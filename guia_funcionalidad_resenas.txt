GUÍA COMPLETA: IMPLEMENTACIÓN DE RESEÑAS DE PRODUCTOS POR PEDIDO

1) EXPLICACIÓN GENERAL
Se añadió un flujo de reseñas por pedido entregado. El usuario entra al histórico, inicia un proceso de valoración para un pedido, puede reseñar uno o varios productos del pedido en modo borrador y después:
- cancelar (descarta todo el borrador), o
- finalizar (persiste reseñas y bloquea nuevas reseñas en ese pedido).

Además, se añadió visualización de reseñas de producto desde catálogo/detalle y desde mostrarProductosCategoria.

2) FLUJO PASO A PASO
2.1 Perfil > Histórico de pedidos.
2.2 Si pedido está “entregado” y no reseñado: botón “Hacer reseña”.
2.3 Vista de proceso de reseñas por pedido: lista de productos del pedido.
2.4 Cada producto permite guardar reseña temporal (texto + valoración 1..5).
2.5 “Cancelar valoración”: elimina borrador en sesión para ese pedido.
2.6 “Finalizar valoración”: inserta todas las reseñas del borrador en BBDD y bloquea nueva reseña del mismo pedido.
2.7 Si el pedido ya fue reseñado, no vuelve a permitir iniciar proceso.

7) CONSULTAS SQL IMPLEMENTADAS
- CREATE TABLE resenas (..., CHECK valoracion BETWEEN 1 AND 5, UNIQUE(usuario_id, producto_id, pedido_id)).
- SELECT para detectar si pedido ya reseñado por usuario.
- SELECT productos de un pedido para reseñar.
- INSERT de reseña final.
- SELECT reseñas por producto con join a usuarios.
- EXISTS en histórico para flag ya_resenado.

8) VALIDACIONES DE DUPLICADOS
- Nivel BBDD: UNIQUE(usuario_id, producto_id, pedido_id).
- Nivel negocio: si pedidoYaResenadoPorUsuario=true, no se acepta seguir reseñando ni finalizar de nuevo.
- Nivel borrador: cada producto en pedido se guarda por clave producto_id (sobrescribe borrador del mismo producto, no duplica).

9) CANCELACIÓN Y FINALIZACIÓN
- Cancelar: borra $_SESSION['resenas_borrador'][pedido_id].
- Finalizar:
  - exige al menos una reseña en borrador,
  - revalida que el pedido no esté ya reseñado,
  - inserta todas las reseñas del borrador,
  - limpia borrador,
  - al existir reseñas persistidas para ese pedido/usuario, queda bloqueado el reintento.

10) VISUALIZACIÓN DE RESEÑAS
- Nueva vista vistas/resenas/ver.php.
- Muestra usuario, valoración numérica, texto y fecha.
- Disponible desde:

  - catálogo (fila de producto),
  - mostrarProductosCategoria (tarjeta de producto de gerente).

NOTA DE REPLICACIÓN EN OTRO PROYECTO
- Mantener siempre doble barrera de integridad (validación en aplicación + índice UNIQUE en BBDD).
- Para “proceso no finalizado”, usar estado temporal en sesión o tabla borrador dedicada.
- Bloqueo de re-reseña por pedido se puede representar por “existencia de cualquier reseña en ese pedido por ese usuario” o por un estado explícito de proceso en una tabla adicional.
